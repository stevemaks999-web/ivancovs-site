Метод: обход всех 348 URL из sitemap_index.xml (17 под-карт, LV/RU/EN), проверка robots.txt, редиректов, заголовков ответа, dev-домена. Только чтение, на сайте ничего не менялось.
Не проверено: PageSpeed Insights (дневная квота API исчерпана), данные Search Console (позиции, индексация), внешние ссылки.

Закрыто: домен (canonical/hreflang/www), description у страниц, canonical везде (0 расхождений), x-default везде, Product/Offer + FAQ у 198 страниц, LocalBusiness, 301 на новые адреса, ответ главной 50 мс. Основной контент (приборы, категории, комплекты, RU/EN) в порядке.
Новое: карта сайта раздулась с 142 до 348 URL за счёт мусора от темы и плагинов, тестовый домен открыт для Google, есть одна страница с ошибкой 500.

## Критично
1. **dev.ivancovs.com открыт для индексации.** Нет noindex, robots.txt разрешает всё, canonical сам на себя, своя карта сайта. Полная копия сайта конкурирует с боевым. Закрыть: noindex (Settings → Reading «Попросить поисковики не индексировать» + заголовок `X-Robots-Tag: noindex` в Cloudflare) и/или защита паролем. Проверить в GSC, не попал ли dev в индекс (`site:dev.ivancovs.com`).
2. **Ошибка 500: `/zīmols/fluke/`** (страница бренда). Либо починить шаблон, либо отдавать 404/редирект и убрать из карты (`product_brand-sitemap.xml`).
3. **В карте сайта 160+ лишних URL.** Лишние под-карты: `portfolio` (20, демо темы: apple-iwatch, radio-desk, black-iphone…), `portfolio_category` (6), `portfolio_type` (2), `testimonials` (11, демо-отзывы), `testimonials_category` (2), `post_tag` (2), `product_tag` (2), `author` (1), `mwb_booking_cost` и `mwb_booking_service` (по 1, отдают 404). Итого около 50 мусорных URL, плюс 404 в карте. Правило: в Yoast отключить показ в поиске и в карте для этих типов (или удалить демо-записи). Это же снимает дубли title/description (5 пар `…-2`) и 27 страниц без H1.

## Важно
4. **12 русскоязычных страниц на латышском корне, без hreflang.** Например `/izmereniya-po-iso-7730/`, `/izmerenie-metodom-k-faktor/`: `<html lang="lv">`, title по-русски, адрес транслитом. Google видит язык-конфликт. Решение: перенести на `/ru/…` с 301 и связать пары hreflang, либо поставить правильный lang и связать. Остальные страницы без hreflang без пары (блог-статьи `spradzienbistamiba`, `ip-klasifikacija`, `hermetiskuma-parbaude`, `kanalu-tirisana`, `logu-insolacijas-piemers`, `ieregulesanas-programma`, `aeracija`, `ieregulesanas-metodes-izvele`, `merinstrumenti`, новость об HVAC) допустимы, если переводов нет; но для самых сильных статей сделать RU/EN.
5. **Главная: два H1** («Sākumlapa» и «Jaunums: Eksperta tehniskais…») и 25 картинок без alt. Один H1 с главным запросом («Mērinstrumentu noma Rīgā» + бренд), «Sākumlapa» убрать, новость понизить до H2/H3.
6. **28 title длиннее 60 знаков** (в основном RU/EN приборы: elektromotoru-gultnu-veselibas-tests EN = 82). Обрезаются в выдаче. Сократить шаблон: «{Название} noma Rīgā | IVANCOVS», название вынести короче.
7. **Alt у картинок:** 86 страниц с картинками без alt (статьи блога по 4–7 штук, главная 25). Приоритет: фото приборов и блог.
8. **Тонкие страницы (<150 слов): 24.** Хабы блога (`/blog-2/`, `/ru/blog/`, `/en/the-blog/`), обучение (`/apmacibas/`, `/ru/obuchenie/`, `/en/training/`), статьи по 117–146 слов (уже в плане, нужны материалы Дмитрия). Добавить вводный текст на хабы.
9. **Нет og:image у 53 страниц:** `/noma/`, 13 категорий, комплекты. Задать общую картинку по умолчанию в Yoast (1200×630), для категорий фото главного прибора.

## Мелочи
10. Короткие title (<30): служебные страницы (tag, portfolio_category, author). Уйдут вместе с п. 3.
11. 15 страниц без description: тоже служебные (теги, портфолио). Уйдут вместе с п. 3; у `product-tag/gaisa-atrums` и `gaisa-plusma` решить: закрыть или заполнить.
12. Заголовки безопасности не отдаются (нет HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy). Прямого влияния на позиции нет, но HSTS полезен. Включить в Cloudflare (SSL/TLS → Edge Certificates → HSTS) и «Transform rules».
13. Нет `llms.txt` (404). Для видимости в ChatGPT/Gemini/Perplexity: добавить короткий llms.txt (о компании, ссылки на каталог, цены, контакты). Низкий приоритет, не влияет на Google.
14. В robots.txt два блока `User-agent: *` (правила WooCommerce и блок Yoast с пустым `Disallow:`). Работает, но лучше слить в один, чтобы не было двусмысленности.
15. Карта `sitemap.xml` и `wp-sitemap.xml` отвечают 301 (ведут на sitemap_index.xml). Это нормально; в GSC отправлена верная карта.
